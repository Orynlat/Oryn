# ORYN

**The Coordination Layer for Base.**

Identity. Reputation. Coordination.

ORYN is building a coordination layer for Base — a shared fabric of **identity**,
**reputation**, and **graph** that ecosystem participants carry with them across
every application. It is an open research initiative.

> The internet connected information. Blockchains connected assets.
> The next layer connects participants. ORYN is exploring what comes next.
